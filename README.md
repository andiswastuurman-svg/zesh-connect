# Zesh Connect

Zesh Connect is a professional Cape Town creator marketing platform connecting businesses, content creators, and agents through creator discovery, campaign workflows, AI-assisted content generation, and a unified asset library.

## Live app

[Open Zesh Connect](https://zeshconnect-hifvp8gy.manus.space/?code=XGLPJqYJgNUcrEyuXaN57h)

## Highlights

- Role-aware workspaces for businesses, creators, and agents
- Cape Town creator discovery with platform filters and match scores
- Campaign creation and management workflows
- AI tools for slogans, captions, ads, briefs, hashtags, CTAs, video concepts, and collaboration responses
- AI-generated image inspiration search and asset saving
- Reusable code, text, content, and prompt library
- Support for Instagram, TikTok, LinkedIn, Facebook, and Twitter/X
- Responsive isometric design system for desktop and mobile

## Tech stack

React 19, Tailwind CSS 4, tRPC 11, Drizzle ORM, MySQL, Express, Vitest, and Manus AI APIs.
